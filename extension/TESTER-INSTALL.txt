Mind World — Beta install (v1.3.1)
================================

REQUIREMENTS
- Google Chrome (desktop)
- Account on claude.ai, chatgpt.com, or gemini.google.com
- Anthropic API key for "Improve" (free at https://console.anthropic.com)

INSTALL
1. Unzip this folder completely.
2. Open Chrome and go to: chrome://extensions
3. Turn ON "Developer mode" (top-right toggle).
4. Click "Load unpacked".
5. Select THIS folder (the one that contains manifest.json).

SETUP
1. Click the Mind World icon in the Chrome toolbar.
2. Sign in with your password or Google account.
3. (Optional) Open "API Settings" → paste your Anthropic key (starts with sk-ant-) → Save API Key.
   Improve works best with an API key; some features need it.

USE
1. Go to claude.ai or chatgpt.com and open a chat.
2. Look for the "Mind World" bar above the message box.
3. Try:
   - Template chips (quick prompts)
   - "Pro" (detailed prompt library)
   - "Improve" or Alt+Shift+M (engineers your draft)

OPTIONAL
- Import past chats for richer Improve: https://mind-world.app

FEEDBACK
Reply to whoever sent you this zip with:
- Which site you used (Claude / ChatGPT / Gemini)
- Whether Improve helped (yes/no + one sentence)
- Any bugs or confusion

TROUBLESHOOTING
- Bar not showing? Refresh the page; make sure you're on a chat page with a text box.
- Improve fails? Check API key in extension popup.
- Extension error on load? Re-unzip; do not edit files in Notepad (breaks encoding).
